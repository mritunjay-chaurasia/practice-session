25- Thread pool in nodejs
    The Node.js thread pool is a set of worker threads (managed by libuv) that execute blocking operations asynchronously, allowing the event loop to stay responsive.
    Node.js uses a thread pool managed by libuv to execute blocking operations like file system and crypto tasks asynchronously, keeping the event loop non-blocking. The default size is 4 threads.
    How Thread Pool Works (Step-by-Step)
        JS code requests async operation (e.g. fs.readFile)
        Task is sent to libuv thread pool
        Worker thread executes task
        Callback is pushed to event loop
        Event loop executes callback

27- Hoisting in js?
Hoisting is javascript behavior where variables or functions decreations are moved at the top of their scope during the compilation phase (before code execution)
    Hoisting Works (Conceptually)
    JavaScript engine:
        Allocates memory for variables & functions
        Executes code line by line
Example:-
    a- var (Hoisted + initialized as undefined)
        console.log(a); // undefined
        var a = 10;

        Behind the scenes:
        var a;
        console.log(a);
        a = 10;
    b- let and const (Hoisted but NOT initialized ❌)
        console.log(b); // ❌ ReferenceError
        let b = 20;
        Why?
        They are in Temporal Dead Zone (TDZ)
        Cannot be accessed before declaration

Hoisting allows variables or functions to be used before they are decleared in the code

28- Currying in js?
Currying in JavaScript is a technique where a function with multiple arguments is transformed into a sequence of functions, each taking one argument at a time.
example===========>
    Instead of:
    f(a, b, c)
    Currying allows:
    f(a)(b)(c)

❌ Normal function==>
    function add(a, b) {
    return a + b;
    }

    add(2, 3); // 5

✅ Curried version
    function add(a) {
        return function (b) {
            return a + b;
        };
    }

    add(2)(3); // 5

Using arrow functions======>
    const add = a => b => a + b;
    add(2)(3);
    
Currying with Multiple Arguments
    const multiply = a => b => c => a * b * c;
    multiply(2)(3)(4); // 24

Why Currying is Useful (Interview Points)
    Function Reusability
        function add(a){
            return function(b){
                return a + b
            }
        }
        const add10 = add(10);

        add10(5); // 15
        add10(20); // 30

    app.post("/login", (req, res) => {
    const user = { id: 1, email: "test@mail.com" }; // validate user
    const ACCESS_TOKEN_EXPIRE = 15 * 60;
    const accessToken = jwt.sign(user, process.env.JWT_SECRET, {

    });

    res.cookie("accessToken", accessToken, {
        httpOnly: true,
        secure: process.env.NODE_ENV === "production",
        sameSite: "strict",
        maxAge: ACCESS_TOKEN_EXPIRE * 1000,
    });

    res.json({ message: "Login successful" });

Backend: Auth Middleware (Protected Routes)
    const authMiddleware = (req, res, next) => {
    const token = req.cookies.accessToken;

    if (!token) return res.status(401).json({ message: "Unauthorized" });

    try {
        const decoded = jwt.verify(token, process.env.JWT_SECRET);
        req.user = decoded;
        next();
    } catch (err) {
        res.status(403).json({ message: "Invalid token" });
    }
    };
