1-  Index in MongoDB?
    Indexing in MongoDB is used to improve query performance.
    Without an index, MongoDB scans every document in a collection to find matching data.
    With an index, MongoDB can directly locate the required documents.

  Types of Indexes:
    a. Single Field Index
        db.users.createIndex({
          email: 1
        })
        Most common.
    b. Compound Index
        db.users.createIndex({
          name: 1,
          age: 1
        })
        Used when queries filter by multiple fields.
    c. Unique Index
        db.users.createIndex(
          { email: 1 },
          { unique: true }
        )
        Prevents duplicate emails.
    d. Text Index
      db.posts.createIndex({
        title: "text"
      })
      Used for searching text.
    e. TTL Index
        Automatically deletes documents after a specified time.
        db.tokens.createIndex(
          { createdAt: 1 },
          { expireAfterSeconds: 3600 }
        )
        Example:
          OTP records
          Session records


Disadvantages of Too Many Indexes
a. More Storage
  Indexes consume disk space.
b. Slower Insert/Update
    When data changes:
      Document Updated
      +
      Index Updated
    Extra work for MongoDB.
How to Decide Which Field to Index?
  Index fields that are:
    Frequently searched
    Used in filtering
    Used in sorting
    Used in joins/lookups
      Examples:
        email
        userId
        createdAt
        status

3- Aggregation in MongoDB
Aggregation in MongoDB is a process used to perform data processing and analysis operations like filtering, grouping, sorting, and transforming documents through aggregation pipelines.

Aggregation operations in mongodb are performed using aggregate method.
db.sale.aggregate([
    {$match:{status:"completed"}},
    {$group:{_id:"$product",totalSales:{$sum:"$amount"}}},
    {$sort:{totalSales:-1}}
])

4- Transactions in MongoDB?
A transaction in mongodb allow you to execute multiple operation as a single atomic unit.
Either all operation sucessfully succeed or all fails(roll back)
Transactions used for update  multiple collection.
example: Transfer money, order+ inventory update, user+ wallet update
Basic transaction flow 
Start Session
→ Start Transaction
→ Perform Operations
→ Commit / Abort
→ End Session

Example: Transfer Money
const session = db.getMongo().startSession();
session.startTransaction();

try {
  const users = session.getDatabase("test").users;

  users.updateOne(
    { name: "A" },
    { $inc: { balance: -100 } },
    { session }
  );

  users.updateOne(
    { name: "B" },
    { $inc: { balance: 100 } },
    { session }
  );

  session.commitTransaction();
} catch (e) {
  session.abortTransaction();
} finally {
  session.endSession();
}

10- Pre and Post Hooks (Middleware) in MongoDB
They allow you to run custom logic before or after certain database operations — like save, find, update, or delete.
Pre hook => Runs before mongodb action (before saving a document) for validate data, hash password, modified fields
Post hook => Runs after mongodb action (after saving a document) for log events, send notification, tigger update

16- 🔴 Redis vs 🟢 MongoDB
  What is Redis?
    Redis is an in-memory-data store mainly used for caching , fast access and temporary data.
    Stores data in RAM
    Extremely fast (microseconds)
    Data is usually temporary
    Support key-value, list , sets
    Typical use cases:
      Caching API responses
      Session storage
      Rate limiting
      Real-time counters

        
  What is MongoDB?
  MongoDB is a NoSQL document database used for persistent application data.
    Stores data on disk
    Data is permanent
    Schema-flexible (JSON-like documents)
    Supports indexing, aggregation, transactions
  Typical use cases:
    User data
    Orders & payments
    Product catalogs
    Logs & analytics

What is ACID ?
  ACID stands for Atomicity, Consistency, Isolation, and Durability. These properties ensure that database transactions are processed reliably and maintain data integrity. Relational databases like PostgreSQL support ACID by default, and MongoDB also supports ACID transactions, including multi-document transactions from version 4.0 onward.
